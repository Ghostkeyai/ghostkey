Next

Picked from what people ask private AI tools for, and kept to what we can prove. Anything that leaves the zero-retention route says so on screen.

Building

Chat with your PDFs, privately

Text is pulled out of the file in your browser and sent like any message. No third-party OCR service ever sees the file.

A receipt for every request

Each answer gets its OpenRouter generation ID, the exact cost and a hash of what was forwarded. Download all of it as CSV.

Confidential models, labelled

Models that run inside hardware enclaves (TEE) get a Confidential tag and a link to their attestation. Same price as the normal route.

Web search, off by default

Switch it on per message. The inspector shows the exact search query, and says plainly that the search provider keeps its own logs.

Personas that stay in your browser

Save a model with your own instructions. Stored on your device only, and shown in the inspector so you see what the model receives.

Spend caps on API keys

Give a key a daily limit or an expiry date, so you can hand it to an agent or a script without risking your whole balance.

Monthly fee report

Fees in, Ghost Credit out, team share out. Built from the hourly files and roots, with a script that re-checks every number.

How this page works

Three rules so a roadmap stays a record, not a wish list.

  • Done means you can open it. An item moves to Shipped only with a link to the page, contract or script that shows it working.
  • No dates for work that hasn't started. An item gets a date once it is being built, not before.
  • Dropped items stay visible. If we cut something, it stays on this page, crossed out, with the reason.

Want something on this list? Ask in the group. The ideas people bring up most get built first.
